## 2. Customer Website Par Kaise Order Karta Hai?

Customer ke liye order karna nihayat aasan banaya gaya hai (sirf 4 steps):

1. **Website Kholta Hai:** Customer mobile ya computer par link kholta hai. Usay sab se pehle Super United Dairy ka royal logo, taaza desi ghee, rabri, makhan aur doodh ki bottles nazar aati hain.
2. **Wazan (Weight) Chunta Hai:** Har item ke sath buttons hotay hain jaise `250g`, `500g`, ya `1 kg`. Button click karne se qeemat khud ba khud badal jati hai.
3. **Cart (Tokri) Mein Dalta Hai:** "Add" button dabate hi item bagair kisi page reload ke foran cart mein chala jata hai.
4. **WhatsApp Par Bhej Deta Hai:** Customer cart kholta hai, apna naam, phone number aur Karachi ka ilaaqa (misal ke tor par: DHA Phase 6, Clifton, Gulshan, Saddar) likhta hai aur **"Confirm Order via WhatsApp"** click karta hai.

## 4. Dukan Ke Counter Staff Ke Liye POS (Bill Counter)

Agar dukan ke andar Saddar counter par koi customer aaye aur slip chahiye ho, to dukan ka staff:
1. Website ke sab se aakhri hissay (Footer) mein jata hai.
2. Wahan chota sa link hai: **"Staff Counter POS"**.
3. Usko click karte hi screen ek **Computer Bill Counter** mein badal jati hai.
4. Wahan se staff ek click mein ghee/rabri select karta hai, cash enter karta hai (misal ke tor par customer ne Rs. 5,000 ka note diya to system khud batata hai ke Rs. 1,170 wapis karne hain).
5. Aur **"Print Thermal Receipt"** dabate hi 80mm ki slips nikal aati hain.
6. Wapis aam website par jane ke liye upar golden button hai: **"← Back to Storefront"**.

## 5. Kya Is Website Ka Koi Mahana Kharcha Hai?

**Jawab: ZERO (0) Mahana Kharcha.**

- Is website mein koi mehnga backend server ya database nahi lagaya gaya jo har mahine $20 ya $50 ka bill mangay.
- Yeh ek modern Single Page Website (SPA) hai.
- Isko aap Vercel, Netlify, ya Cloudflare Pages par **hamesha ke liye bilkul free** host kar sakte hain, ya apni kisi bhi aam website hosting (cPanel) par daal sakte hain.

## 6. Kal Ko Agar Rates ya Phone Badalna Ho To Kaise Badlein?

Aksar dukan walon ko dar lagta hai ke code kharab na ho jaye.  
Lekin aapko pareshan hone ki bilkul zaroorat nahi hai!  

Puri website ki har qeemat, phone number, aur item **sirf EK FILE** ke andar rakhi gayi hai:

📁 **File Ka Pata:**  
`src/data/products.js`

Aap kisi bhi aam text editor (Notepad, VS Code ya GitHub) mein is file ko khol kar aaram se edit kar sakte hain.

---

### 6.1 WhatsApp Number Aur Phone Badalna

Is file mein sab se neeche aapko `SHOP_INFO` nazar aayega:

```javascript
export const SHOP_INFO = {
  name: 'Super United Dairy',
  tagline: 'Pure Desi Ghee, Farm Butter, Flavored Milk & Traditional Karachi Sweets',
  address: 'V25J+M4J, Dr. Daudpota Rd, Saddar, Karachi, Sindh, Pakistan',
  phone: '+92 325 3456015',      // Yeh dukan ka call number hai
  whatsapp: '923253456015',      // YEH WHATSAPP NUMBER HAI (Bina space aur bina + ke)
  hours: 'Open Daily: 6:00 AM – 1:00 AM (Midnight Fresh Supply)',
};
```

Agar WhatsApp number badalna ho to bas `'923253456015'` ki jagah apna naya number likh dein (bas shuru mein `92` zaroor lagayein aur koi space ya `+` na dein).

---

### 6.2 Kisi Cheez Ka Rate (Price) Badalna

Isi file ke shuru mein saray products likhay hain. Misal ke tor par Desi Ghee:

```javascript
{
  id: 'desi-ghee',
  name: 'Pure Desi Ghee (Danedar)',
  urdu: 'خالص دیسی گھی (دانے دار)',
  price: 2400, // <--- Yahan 1kg ka base rate badlein
  weights: [
    { label: '500g', price: 1200 }, // <--- 500 gram ka rate yahan badlein
    { label: '1 kg', price: 2400 }, // <--- 1 kilo ka rate yahan badlein
    { label: '2 kg', price: 4700 }, // <--- 2 kilo ka rate yahan badlein
  ],
}
```

Aapne sirf number badalna hai (misal ke tor par `2400` ko `2500` kar dein). Website par khud ba khud naya rate show hona shuru ho jayega!

### 6.4 Delivery Charges Badalna

File: `src/components/CartDrawer.jsx`  
Line number ~120 par delivery ka formula likha hai:
```javascript
const deliveryFee = subtotal >= 3000 || subtotal === 0 ? 0 : 150;
```
- `150` ka matlab hai: Har order par Rs. 150 delivery charge honge.
- `3000` ka matlab hai: Agar customer ka bill Rs. 3,000 se zyada ho to delivery FREE ho jayegi.
- Agar aap delivery Rs. 200 karna chahte hain to `150` ko `200` kar dein.

---

`src/data/products.js` mein `SHOP_INFO.address` aur `SHOP_INFO.hours` mein jo likhenge, wahi website par header aur footer mein show hoga.

## 8. Website Ko Internet Par Live Kaise Karein?

Agar aapne website ko kisi domain (jaise `superuniteddairy.com`) par live karna hai:

### Tareeqa 1: Vercel Par (1 Minute Mein Free Live)
1. [vercel.com](https://vercel.com/) par free account banayein.
2. Apni GitHub repository (`https://github.com/Zohair313/dairy`) ko connect karein.
3. "Deploy" ka button dabayein.
4. Website foran live ho jayegi aur aapko free SSL certificate (green padlock `https://`) mil jayega.

### Tareeqa 2: Apni cPanel Hosting Par
1. Computer terminal mein command chalayein:
   ```bash
   npm run build
   ```
2. Project ke andar ek `dist` naam ka folder ban jayega.
3. Apne cPanel File Manager mein jakar `public_html` ke andar is `dist` folder ki saray files upload kar dein.

## 9. Aam Sawalaat (FAQs)

#### S1: Agar customer bagair internet ke WhatsApp button dabaye to kya hoga?
**Jawab:** Mobile phone khud ba khud WhatsApp app ko open kar dega. Jab bhi customer internet se connect hoga, message shopkeeper ko deliver ho jayega.

#### S2: Kya customer credit card ya online payment kar sakta hai?
**Jawab:** Yeh system Cash on Delivery (COD) aur Direct WhatsApp confirmation ke liye banaya gaya hai jo Karachi ke traditional dairy business ke liye sab se ziada kamyab aur tez tareen model hai. Agar customer online payment chahta hai, to shopkeeper WhatsApp par apna Raast ID ya EasyPaisa/JazzCash number bhej kar payment verify kar sakta hai.

#### S3: Kya mobile par website theek chalti hai?
**Jawab:** Ji han, website ko chotay mobile (iPhone, Samsung, Android) se lekar computer aur tablet tak har screen size par test kiya gaya hai. Button aur text mobile ke hisab se bilkul perfect fit aate hain.
